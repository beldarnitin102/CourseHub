# 🎓 CourseHub – AI Powered Learning Management System

CourseHub is a Full Stack AI-powered Learning Management System (LMS) that enables instructors to create and manage courses while providing students with an interactive learning experience using AI-powered tools such as AI Mentor, AI Study Planner, AI Projects Generator, AI Interview Preparation, Smart Notes, and AI Recommendations.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/beldarnitin102/CourseHub.git
```

---

## Backend

```bash
cd backend
npm install
npm run dev
```

---

## Frontend

```bash
cd frontend
npm install
npm run dev
```
